# Grano & Aroma | Cafetería de Especialidad

Proyecto desarrollado como **Pre-Entrega de la Tecnicatura / Curso de Desarrollo Web (Talento Tech)**.

## 📌 Propósito del Sitio
**Grano & Aroma** es un sitio web E-Commerce y de presentación para una cafetería de especialidad. Su objetivo principal es ofrecer una experiencia de usuario moderna y accesible, permitiendo a los amantes del buen café conocer el catálogo de granos de origen, ver reseñas de clientes, aprender sobre métodos de extracción mediante contenido multimedia y contactarse de forma directa o realizar pedidos especiales.

## 🛠️ Tecnologías y Características Técnicas
- **HTML5 Semántico:** Uso correcto de etiquetas (`header`, `nav`, `main`, `section`, `article`, `footer`) y pautas de accesibilidad WCAG (`aria-*`, `skip-link`).
- **CSS3 Moderno:** 
  - Estilos personalizados con variables CSS.
  - Tipografías importadas desde **Google Fonts** (*Playfair Display* y *Poppins*).
  - Maquetación responsiva utilizando **Flexbox** (para la sección de productos y tarjetas) y **CSS Grid** (para la sección de reseñas).
  - Adaptabilidad mediante **Media Queries** en el formulario de contacto y diseño general.
- **Formulario Funcional:** Integrado con el servicio de gestión de formularios de **Formspree**.
- **Multimedia:** Inclusión de imágenes optimizadas con carga diferida (`loading="lazy"`) y un reproductor de video embebido (`iframe`).
